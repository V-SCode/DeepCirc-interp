# topology/

Cross-topology design-rule pipeline for the DeepCirc paper supplementary
figures **S10–S13**. Produces population-scale analyses of how circuit
topology composition shapes predicted circuit and growth scores.

## Pipeline phases

| Phase | Script(s) | Output |
|---|---|---|
| **A** | `scripts/00_select_targets.py` | `configs/target_functions.yaml` — 20 target Boolean functions |
| **B** | `scripts/01_generate_topologies.py` + `slurm/p1_ppo.sbatch` | `final_shared_registry.pkl` per target (PPO+GAT, SLURM-GPU) |
| **B'** | `scripts/01_5_parse_registries.py` + `slurm/p1_5_parse.sbatch` | Flat topology table from registry pickles |
| **C** | `scripts/03_assemble_population.py` + `scripts/_population_filter.py` | G3 population manifest (4–7 reg, agent-only, up-to-5 per cell) |
| **D** | `scripts/04_train_mlps.py` + `slurm/p4_mlp_train*.sbatch` | Stage-2 MLPs per (topology × {circuit, growth}) |
| **E** | `scripts/05_qc_stratify.py`, `07_5_best_perm_selection.py` | QC-passed topologies + per-topology best perm |
| **F** | `scripts/07_score_design_space.py` | Full design-space predictions per topology |
| **G** | `scripts/{08,09,22,23_2,23_3,24,26,27,29}*.py` | L1/L2/L3 analyses feeding figS10/S11/S12/S13 |

## SLURM templates

Templates under `scripts/slurm/` were developed and tested on MIT Engaging /
ORCD. Adapt the `#SBATCH --partition` / `--gres` / `--account` lines to your
local cluster.

## Configs

- `configs/target_functions.yaml` — the 20 target Boolean functions (generated by `00_select_targets.py`)
- `configs/pipeline.yaml` — pipeline defaults (size scope, QC thresholds, sampling cap)
